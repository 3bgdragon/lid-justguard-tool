# 저스트가드 — TFC판 사용법

판정 시간·그로기·근접 방어를 선택할 수 있습니다. 속성 후속 피해 차단은 현재 근접 방어와 연동됩니다.

이 배포물은 **TFC 전용판 tfc-v1.1.1**입니다. 기존 독립 실행판은 별도 배포물이며 이 ZIP에 포함하지 않습니다.
릴리스의 `*-tfc-v1.1.1.zip` 첨부 파일을 받으세요. GitHub의 Source code ZIP은 전용 배포물이 아닙니다.
Node.js 22.13 이상과 TFC Installer 2.5.6.0이 필요합니다. 대응 빌드: 25386710.
게임을 종료하고 세이브를 별도로 백업하세요.
기존 독립 실행판을 사용했다면 해당 도구로 먼저 제거하세요. 두 방식을 혼용하지 마세요.

## 처음 설치

1. 옵션을 바꾸려면 원본 TFC판의 **configure-guard-tfc.bat**를 실행하세요. 출력된 새 모드 폴더를 사용합니다. 기본 설정(0.5초·그로기 ON·근접 방어 ON)을 쓰면 이 단계는 생략합니다.
2. TFC에서 **선택한 모드 폴더**를 적용하세요. 기본 설정은 이 `tfc` 폴더입니다.
3. **같은 모드 폴더의 run-tfc.bat → 1번 설치 마무리**를 실행하세요.
4. 완료 안내가 나오면 게임을 실행하세요.

`run-tfc.bat`은 게임 설치 폴더 또는 `BrgGame-Steam.exe` 경로를 물어봅니다.
1번이 필요한 연결·보조 기능을 함께 처리하므로 별도로 해시 연결을 또 할 필요는 없습니다.

## 제거

1. 게임 종료 후 TFC에서 이 모드를 제거하세요.
2. 같은 모드 폴더의 **run-tfc.bat → 2번 제거 마무리**를 실행하세요.

## 가드 옵션 변경

configure-guard-tfc.bat로 새 폴더 생성 → TFC에서 이전 가드 프리셋 제거 → 새 폴더 적용 → 새 폴더의 run-tfc.bat 1번.
서로 다른 가드 프리셋을 겹쳐 적용하지 마세요. 모두 순정이면 가드 모드를 제거하고 2번으로 마무리하세요.

## 문제가 있을 때만

`run-tfc.bat → 3번`: 연결 상태 확인.
`run-tfc.bat → 4번 고급 메뉴`: 다른 TFC 패치 변경 후 연결 갱신·이전 EXE/DB 설정 복원·중단 작업 복구.
다른 TFC 모드로 UPK가 바뀌었다면 고급 메뉴의 1번으로 연결을 갱신하세요.

백업은 게임 폴더의 상위 **LET-IT-DIE-TFC-backups**에 있습니다.
UPK 복원은 TFC, EXE·DB 설정 복원은 보조 도구가 담당합니다. 구매·데칼·탄약 등 세이브 결과는 되돌리지 않습니다.
`LID-TFC-State`와 백업을 수동 삭제하지 마세요. 같은 UPK 객체를 바꾸는 외부 모드와는 충돌할 수 있습니다.
